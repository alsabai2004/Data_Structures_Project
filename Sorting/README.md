# 🔄 Sorting Algorithms

A Python implementation of common sorting algorithms for organizing data in ascending or descending order.

---

## 📌 Overview

Sorting is the process of arranging elements according to a specific order.

This module demonstrates several classic sorting techniques and their algorithmic characteristics.

---

## 🧩 Implementation

Main directory:

Sorting/

The module contains the sorting algorithm implementations and supporting code.

---

## ⚙️ Sorting Algorithms

| Algorithm | Description |
|---|---|
| Bubble Sort | Repeatedly swaps adjacent elements |
| Selection Sort | Selects the minimum element for each position |
| Insertion Sort | Inserts each element into its correct position |
| Merge Sort | Divides data and merges sorted parts |
| Quick Sort | Partitions data around a pivot |
| Heap Sort | Uses a heap to organize elements |

---

## 🧠 Bubble Sort

Bubble Sort repeatedly compares neighboring elements and swaps them when they are in the wrong order.

Average Time:

O(n²)

Worst Time:

O(n²)

Space:

O(1)

---

## 🧠 Selection Sort

Selection Sort repeatedly finds the smallest element from the unsorted portion and places it in the correct position.

Time:

O(n²)

Space:

O(1)

---

## 🧠 Insertion Sort

Insertion Sort builds the sorted portion one element at a time.

Best case:

O(n)

Average case:

O(n²)

Worst case:

O(n²)

Space:

O(1)

---

## 🧠 Merge Sort

Merge Sort uses divide-and-conquer.

The array is divided into smaller parts, sorted, and then merged.

Time:

O(n log n)

Space:

O(n)

---

## 🧠 Quick Sort

Quick Sort selects a pivot and partitions the elements around it.

Average Time:

O(n log n)

Worst Time:

O(n²)

Space:

O(log n) average for recursive calls.

---

## 📊 Complexity Comparison

| Algorithm | Best | Average | Worst |
|---|---:|---:|---:|
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Selection Sort | O(n²) | O(n²) | O(n²) |
| Insertion Sort | O(n) | O(n²) | O(n²) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) |
| Heap Sort | O(n log n) | O(n log n) | O(n log n) |
